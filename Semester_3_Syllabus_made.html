💡 Smart Study Tips for 3rd Sem

🧮
OS & DAA: Solve Numericals Daily
Page replacement, disk scheduling, and scheduling algorithm numerical problems appear every exam. Practice 5 numericals/day for each algorithm. Write the steps, not just the answer.
☕
Java: Code Daily, Don't Just Read
Java OOP is 90% hands-on. Write inheritance programs, thread programs, and exception programs yourself. Read code, write it, break it, fix it. That's how Java sticks.
📐
Discrete Maths: Understand, Don't Memorize
Graph theory and group theory questions can be solved logically if you understand definitions. Draw graphs, build truth tables by hand. Formulae follow from understanding.
⚡
EEE: Draw Circuits & Solve Problems
For AC circuits and Op-Amp problems, draw the phasor diagram or circuit first. Nodal & mesh analysis problems follow a fixed template — master that template for 80% of numericals.
